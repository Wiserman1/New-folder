# Concrete Bridge Deck Inspection App

This app is ready for Streamlit deployment.
created by 23/eg/ee/027
## Run locally

```bash
pip install -r requirement.txt
streamlit run streamlit_app.py
```

## How to upload an image in Streamlit

1. Start the app.
2. Click the upload button labeled "Upload concrete surface photograph...".
3. Choose a JPG or PNG image from your computer.
4. The app will display the image and show the result.

## Deploy on Streamlit Cloud

1. Push this repository to GitHub.
2. Open Streamlit Cloud.
3. Create a new app from the repository.
4. Set the main file to `streamlit_app.py`.
5. If you want to use the TensorFlow path, keep model.h5 available in the repo or via Git LFS.
